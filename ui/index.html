第 3 步：保存 / 启用

说明

  • Harness 仍是 Grok Build；只有模型推理走 CodeBuddy 订阅。
  • /v2/chat/completions 是推理端点，不提供模型枚举；Switch 只读同步 WorkBuddy 本机的最新产品目录。
  • 上游仅支持流式；Switch 代理会清洗 finish_reason:""，避免 Grok 反序列化失败。
  • 进程内路径：/codebuddy-proxy/v1（需使用含本功能的 Switch 版本）。
